Claude Code 和 OpenAI Codex 通用的 skill

把要做几个小时的项目交给 AI，Marathon 一直做到达标为止

它先和你定好目标和评分标准，再派多个 worker 并行干活；每一轮由两个不同的模型独立打分，直到分数达标、分数不再上涨或预算用完。最后提交、上线，并给你一份决策备忘。

它能替你做什么

只问一次，然后开干

开工时最多 5 个问题，默认值已经选好，点一次确认就行；你不在时，10 分钟后按默认开跑。

目标可以检验

开工前就写下对标对象、数字目标和及格线，“做完了”是一个分数，而不是一种感觉。

并行的 worker

同时派多个 worker（默认的 balanced 模式最多 4 个）写代码、做研究、跑测试、改页面。每个只交回一段简短总结，完整报告存成文件。

双模型评审闸门

Claude Opus 和 GPT-6-Astra 独立给同一个冻结版本打分；分歧大时按证据裁决，而不是取平均。

不用说“继续”

停止 hook 让它一直跑下去，直到满足停止条件：达标、连续三轮没有实质进步、预算用完，或者只有你能处理的事。

不怕上下文变长

进度存在 STATE.md 里，不靠记忆。新 lead 在空档接班，从上一个停下的地方继续。

花费算得清

每个 worker 记一行账；marathon.py usage 按 token 类型和价格算出 Claude 花费，钱花在哪一目了然。

交付后再汇报

最终闸门就是独立复核。lead 提交、上线、核对线上版本，最后给你一份备忘：改了什么、局限、下一步选项。

这些事它永远不替你决定
登录、密码、付款、公开发布、删除东西和追加预算，一定等你回答；其他事情才按默认值走。

一键安装

  1. 下载 marathon-skill.zip，解压到任意位置。
  2. 运行安装程序。Windows：双击 install.cmd；macOS / Linux：sh install.sh。它会装到你已有的 Claude Code 和 Codex 里，旧版本会先备份。
  3. 开始一个项目。在 Claude Code 或 Codex 里说“用 marathon 做……”，回答问题，或者直接让它按默认走。

常见问题

它会不会不问我就花钱或公开发布？

不会。付款、公开发布、删除、登录和追加预算一定由你决定；其他事情按开工时你看到的默认值走。

它提问时我不在怎么办？

普通问题 10 分钟后按默认值处理（等待时间可以改，也可以设成 0）。必须你定的事会先放着，其他工作照常进行。

必须同时有 Claude Code 和 Codex 吗？

Claude Code 是必需的：lead 和评审闸门都在 Claude 上运行。Codex CLI 只在默认的 Codex worker 模式下需要（登录 ChatGPT，或配置你自己的 API）；全 Claude 模式不需要它。

跟写一段很长的提示词有什么不同？

长提示词会忘、会跑偏、会停。Marathon 把状态写在文件里，开工前定好目标，每轮由两个独立模型打分，在上下文变差之前换 lead，按规则停下，而不是看心情。

适合什么样的项目？

要花几个小时、做得好不好能评判的：网页应用和业务系统、网页游戏、数据网站和地图集、带数字和结论的研究报告。两分钟能修好的小事不需要它。
