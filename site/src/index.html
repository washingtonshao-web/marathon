What it does for you

Asks once, then works

At most five questions at kickoff, each with a default already selected. Answer with one click, or walk away: after 10 minutes it starts on the defaults.

Targets you can check

The charter fixes a benchmark, numeric targets and a pass mark before work starts, so “done” means a score, not a feeling.

Parallel workers

Several bounded workers at a time (four in the default balanced mode) write code, research, run tests or polish pages. Each returns a short summary; full reports go to files.

Two-model review gate

Claude Opus and GPT-6-Astra grade the same frozen commit independently. Big disagreements are ruled on with evidence, not averaged away.

Never needs “continue”

A stop hook keeps the run going until a stop rule holds: target met, three rounds without real gains, budget used, or something only you can do.

Survives long contexts

Progress lives in STATE.md, not in memory. A fresh lead takes over at a quiet point and picks up exactly where the last one stopped.

Counts the cost

Every worker gets a ledger row. marathon.py usage prices Claude tokens by type, so you see where the money goes.

Ships, then reports

The final gate is the independent review. The lead commits, deploys, checks the live version and ends with a memo: what changed, limits, options.

It never decides these for you
Signing in, passwords, payments, publishing something publicly, deleting things and adding budget always wait for your answer, even when everything else runs on defaults.

Both judges preferred their own model in every disputed case, so rulings rest on tests and reproduced bugs only. GPT-6.1-Sol became the default worker afterwards; Astra stays one setting away.

Install in one click

  1. Download marathon-skill.zip and unzip it anywhere.
  2. Run the installer. Windows: double-click install.cmd. macOS / Linux: sh install.sh. It installs into Claude Code and Codex, whichever you have, and backs up any older copy.
  3. Start a run. In Claude Code or Codex, say “use marathon to build …” with what you want. Answer the questions or let them default.

Questions people ask

Will it spend money or publish things without asking?

No. Payments, public publishing, deletions, sign-ins and extra budget are always your decision. Everything else follows the defaults you saw at kickoff.

What if I'm away when it asks something?

Ordinary questions take their defaults after 10 minutes (you can change the wait or set it to zero). Must-decide items are parked while the run continues with everything else.

Do I need both Claude Code and Codex?

You need Claude Code: the lead and the review gate run on Claude. The Codex CLI is needed only for the default Codex-worker mode (signed in to ChatGPT, or with your own API endpoint). All-Claude mode works without it.

How is this different from a long prompt?

A long prompt forgets, drifts and stops. Marathon keeps state in files, fixes targets up front, scores every round with two independent models, rotates the lead before its context degrades and stops by rule, not by mood.

What kinds of projects suit it?

Anything that takes hours and can be judged: web apps and business systems, browser games, data sites and atlases, and sourced research reports with numbers and a recommendation. Not a two-minute fix.
