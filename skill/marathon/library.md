# Reusable assets

Reuse your assets folder before sourcing new material. Keep a README index by category: art, maps, fonts, QA, datasets and process templates. Copy assets into each project before adapting them. Keep large binaries outside Git, with hashes and provenance in a manifest. At delivery, promote reusable improvements to your own library and sync.

Use your deploy command and your static host. Asset folders, credentials and host access belong to your environment; this skill installs none of them.
