# 动画制作：|话题变成|纪录片

给它一个题目，比如“波兰史”或“丝绸之路”，它会写剧本、请另一个模型核查事实、按这个题材的传统画风逐镜头作画，配上会动的历史地图和中文解说，再把配音转成文字和原稿核对，最后交出一部 2–5 分钟、带字幕的 1080p 短片和一个手机版。按 3 分钟一部估算，额外要付的只有豆包配音和音效，约 4 元；画画和动镜头用你已有的 ChatGPT、Google 订阅，其余软件都是免费的。

## 成片是什么样

<figure class="m-shot"><img src="/img/poland-frames.webp" alt="《波兰千年》的 12 个画面：油画风格的历史场景，左上角是标题，底部是字幕" width="1600" height="1266"><figcaption>《波兰千年》（约 3 分钟）里的 12 个画面，左上角数字是片中秒数。油画风格对应波兰的绘画传统，二战段落改用黑白。</figcaption></figure>

- 每个镜头一幅 **AI 画的历史画**，配缓慢的推拉镜头运动。
- 穿插 2–3 段**会动的历史地图**：疆域扩张、行军路线、瓜分与边界变化。
- 2 个镜头用 **Google Flow 让画面真正动起来**，另有最多 2 个镜头做成 **2.5D 视差**（画面分出前后景，带景深运动）。
- 低沉庄严的**男声解说**；引用历史人物原话时**换另一个声音来读**，字幕用斜体并注明出处。
- 开头“冷开场”：先放全片最戏剧性的一幕，再出片名，然后从头讲起。
- 可选“同年中国”角标：在关键镜头右上角标出同一年中国的年号，比如“同年中国 · 明万历十六年”。
- 环境音效、配乐、标题、字幕、片尾卡片齐全。

| 规格 | 数值 |
|---|---|
| 时长 | 单片 2–3 分钟，专题片最长 5 分钟 |
| 画面 | 1920×1080，30 帧 |
| 响度 | -16 LUFS |
| 手机版 | 720p，小于 30 MB |
| 渲染时间 | 成片每分钟约 8 分钟（作者电脑上的经验值） |

作者用它做了一个世界历史系列：26 部国家与地区史，加 13 部专题（丝绸之路、白银、瘟疫、冷战等）。

## 一题一风格

它不会一套画风用到底，而是按题材本身的视觉传统来选：

| 题材 | 画风 |
|---|---|
| 中国史 | 水墨、工笔、青绿山水，用红色印章 |
| 日本 | 浮世绘，印章改用日本的判子 |
| 伊朗、中东 | 波斯细密画 |
| 欧洲 | 油画、蛋彩画 |
| 近现代 | 木刻、海报画、水彩、明亮插画 |

合成时有两套底色：`ink`（宣纸底、黑字标题）和 `dark`（深色油画光晕、米色标题），每部片还可以选黑白、偏红或明亮的色调。动笔之前，它会先写一张风格卡（`STYLE.md`）：媒材、配色、光线、构图规则、每个镜头的一句历史参照。提示词只写要画什么，不写不要画什么，检查程序会专门查这一条。

## 制作流程

| 步骤 | 做什么 | 把关 |
|---|---|---|
| 0 体检 | `mp.doctor` 检查 Python 包、ffmpeg、字体、地图数据、出图渠道、语音密钥、显卡、视差模型、语音识别和 Flow 插件 | 缺什么就打印怎么补 |
| 1 定声音和字体 | 单片：试听 3–5 个声音，用 2–3 套字体各渲染 3 帧真实画面，你挑一个；系列片按系列规格书，不再问你 | 其他事一概不问 |
| 2 写剧本 | 15–25 个镜头，每个 1–2 句，约每秒 4 个汉字；为耳朵写，多写具体画面和人物，少列人名年代 | **第一道关：事实核查** |
| 3 剧本体检 | 检查重音位置、字数和时长、数字读法、多音字、地图配置 | 不通过不许配音 |
| 4 画面 | 每个镜头一幅画；画完拼成总览图逐张检查；生成动画地图、Flow 镜头和视差镜头 | 时代错乱、地标画错的一律重画 |
| 5 配音 | 解说和引用分别配音 | **第二道关：用数字检查听感** |
| 6 音效、配乐、合成 | 环境音效、真实名曲配乐、解说时音乐自动压低、全片响度统一 | **第三道关：画面审查** |
| 7 交付 | 生成字幕、烧录字幕的 1080p 版和手机版 | 先看手机版，每部片只改一轮 |

写剧本时还有几条硬规则：**重音词不能放在句尾**，因为 AI 配音在句尾常常压不住重音；多音字和人名要标读法，比如“百济”念作“百寄”，字幕仍显示原字；数字要按读法写，“1588”写成“一五八八”。

## 三道质检关

### 第一道：事实核查

由**另一个模型**逐句核查，写稿的不能自己查。它会核对每一句话、每个“同年中国”年号和每张地图，修正日期和以偏概全的说法，把传说标成“相传”，在叙事有断档的地方补上过渡。

### 第二道：用数字检查听感

| 检查项 | 标准 |
|---|---|
| 重音 | 重音词比周围响 1.15 倍以上，或者音调更高 |
| 停顿 | 该停的地方至少停 0.22 秒 |
| 语速 | 偏差在 ±15% 以内 |
| 转写核对 | 用 Whisper 语音识别把配音转成文字，按不带声调的拼音和原稿对比，吻合度 ≥0.90 |

不合格的句子单独重录，或者用一次比一次强的重音指令重录，最多 3 次，取最好的一条；3 次还不行就标出来交给你。专题片还会逐句测音高和语速：某句偏离全片中位数 2.5 个半音以上，或者和前后句相差 3 个半音以上，就重录，避免听起来像换了个人。

### 第三道：画面审查

抽 12 帧拼成一张总览图，交给另一个模型独立审查，同时检查时长、响度、音画同步、标题和字幕。合成程序本身还会做两件事：

- **标题避开人脸**：先检测人脸，再在四个角里挑最干净的位置放标题。
- **标题对比度达标**：逐像素计算文字和背景的对比度，不到 4.5:1 就自动加衬底或换颜色。

## 用到的模型和工具

| 环节 | 模型或工具 |
|---|---|
| 写剧本 | 当前会话：Claude Code 或 Codex |
| 事实核查、画面审查 | 另一个模型：GPT-6-Astra 或全新的 Claude Opus |
| 画画 | gpt-image-2.5（有图像 API 时），否则用 Codex 内置画图走 ChatGPT 订阅，约 70 秒一张 |
| 画面动起来 | Google Flow 图生视频，4 秒，订阅额度 |
| 景深视差 | Depth Anything V2，本地运行，有 NVIDIA 显卡更快 |
| 解说与引用 | 豆包 Seed-TTS 2.0，默认解说声音“擎苍”；没有密钥时用免费的微软 Edge 语音 |
| 配音转写核对 | Whisper 语音识别，本地运行 |
| 环境音效 | 本地音效库、BBC 音效档案、豆包 Seed Audio |
| 配乐 | 真实录音；没有合适的就按地域调式生成占位音乐 |
| 历史地图 | historical-basemaps 和 Natural Earth，加上自建的唐、北宋、明、清疆域数据 |
| 合成与字幕 | ffmpeg、libass，中文分词用 jieba |

开源历史地图有不少错误，比如把公元 700 年的中国标成“隋”、1400 年标成“大汗国”，所以它自带一份修正过的中国朝代疆域；按数据说明，边界误差约 50–150 公里，属于地图比例尺上的精度。

## 缺东西也能做

| 缺什么 | 怎么处理 |
|---|---|
| 豆包语音密钥 | 改用免费的 Edge 语音，不生成 AI 音效 |
| 视差模型 | 视差镜头改成推拉镜头 |
| Flow 插件或订阅 | Flow 镜头先改成视差，再不行就用推拉镜头 |
| Whisper | 跳过转写核对，只看重音、停顿和语速 |

至少需要一个出图渠道。有 ChatGPT 订阅的话，装好 Codex 并登录，就能免费出图。

## 设计上的独特之处

1. **一题一风格。** 波兰片像油画，日本片像浮世绘，中国片是水墨，配乐和音效也跟着地域走。
2. **用数字管好不好听。** 测重音、停顿、语速，再把配音转成文字和原稿核对；一般的 AI 配音生成完就不管了。
3. **写的人不审自己。** 事实和画面都交给另一个模型检查。
4. **动静搭配控成本。** 大部分镜头是画加镜头运动，只在最关键的 2 个镜头花 Flow 额度。
5. **较真历史准确性。** 修正开源地图的错误，“同年中国”逐条核对年号，传说标“相传”，不做假的“历史照片”，不画在世领导人。
6. **每一步都能断点续做。** 剧本、配音、画、动镜头、成片都存成文件，从缺的那一步接着做。

## 11 月新增

2026 年 11 月 6 日这一版新增的东西：

- **讲概念、讲地理的专题片**：3–5 分钟、22–34 个镜头。先定一句观众看完能复述的中心句；开头提出问题，中间用 3–4 个案例证明它，而不是罗列事实；最后 20 秒回答问题，并说明这个说法的局限。需要对比时，把两幅画并排放。
- **地形底图和三维飞越镜头**：历史地图可以换成水彩风格的地形底图（山体阴影加分层设色，标出关隘、山峰和河流）；还能做 1080p 的三维地形飞越镜头，镜头按解说的时间点依次飞到每个地方。
- **一套声音标准**：解说保持 48 kHz，整片响度 -16 LUFS，相邻两句的音量差不超过 2 LU；句间停顿按意思分三档；合成配音下面不垫人造底噪。交付前用 `mp.audiocheck` 量一遍，不合格就不交付。别处做的画面（比如 HyperFrames 动画）也用 `mp.voiceover` 来配解说和混音。
- **配音更稳**：每个镜头的语气只从五档里选（平静、稍沉重、稍紧张、稍舒缓、稍振奋），免得一句话听起来像换了个人；容易读错的多音字改写或注音。语音识别和稿子对不上时，先用本地音频模型（`mp.listen`）再听一遍，确认真读错了才重录。
- **尊重史实**：每个日期、数字、人名和引语都进事实表并注明出处；有争议的数字写成范围，并说明是谁的估计；传说和小说里的情节会标明。
- **独立的成片评审**：成片交给一位没参与制作的评审，看每个带标题的镜头、每张地图，听配音，对字幕时间，按评分表打分；不通过就改一轮，再换一位新评审重新打分。系列片最后还有一次跨片检查，看有没有重复、前后是否一致。
- **交付位置**：成片和手机版留在项目的 renders 文件夹里，也可以同时复制到你指定的网盘目录，做完会告诉你文件在哪。

## 下载和安装

1. 下载 [animation-making.zip](/animation-making.zip)（约 5 MB），解压到一个固定的位置，比如“文档”。装好后不要再移动：skill 会指向这个文件夹。
2. Windows：双击 `install.cmd`。macOS 或 Linux：在文件夹里运行 `sh install.sh`。它会安装 Python 包、ffmpeg、字体和历史地图数据（约 400 MB），并把 skill 装进 Claude Code 和 Codex。
3. 最后一屏是体检结果。显示 READY 就可以开始；显示 NOT READY 时，会逐项写明还缺什么、怎么补。
4. 重启 Claude Code 或 Codex，说：“用动画制作做一部关于 xx 的短片”。

需要 Python 3.10 或更新版本；Windows 安装 Python 时勾选 Add python.exe to PATH。视差、转写核对、豆包密钥和 Flow 插件都是可选的，开通步骤写在压缩包里的 `安装说明.txt` 中，也可以直接让 AI 带你一步步做。

豆包语音的生成内容受火山引擎服务条款约束；Edge 语音仅供个人使用。
